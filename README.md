# Monsterhöhle & Fischwrack

Ein Rechenspiel für die 1. Klasse (Zahlenraum bis 20, Ergebnisse 3 bis 15).

Monster laufen in eine Höhle oder Fische schwimmen in ein Wrack, andere kommen dazu oder verschwinden wieder.
Am Ende wird gefragt, wie viele jetzt im Versteck sind.

## Stufen

1. **Leicht:** nur Plusaufgaben
2. **Mittel:** Plus- oder Minusaufgaben
3. **Schwer:** zwei Rechenschritte hintereinander
4. **Knobeln:** Platzhalteraufgaben („Wie viele sind dazugekommen?“)

## Hilfen und Belohnungen

- Taschenlampe bzw. Laternenfisch: zeigt pro Figur ein leuchtendes Auge
- Vorlesefunktion („Ton an“)
- Drei richtige Antworten in Folge: Tanz, fünf in Folge: Tanz mit Feuerwerk

## Spielen

Das ganze Spiel steckt in einer einzigen Datei, `index.html`. Es braucht keinen Server und keine Installation.
Sterne werden lokal im Browser gespeichert.
